## Notes

* `alef_maqsura` recall is low by design: ayaspell accepts the `ي` spelling of many words
  (`إلي`, `علي`, `انتهي`, `يرجي`, ...), and a generic rule produced false positives on legitimate
  words (`تحوي`, `سحابي`, the name `علي`). Only a closed list (`الي`, `حتي`, `متي`, `مستشفي`, `فى`)
  and dictionary-invalid forms are flagged, in line with "low false positives beat recall".
* `taa_marbuta` misses are words where the `ه` spelling is a valid pronoun-suffixed word
  (`مدرسه` = "his teacher"); only `ال`-prefixed and dictionary-invalid forms are flagged.
* Readability (`/api/spelling/readability`) uses OSMAN, El-Haj & Rayson, LREC 2016 (https://aclanthology.org/L16-1038/). `app/spelling/osman.py` is an independent port verified against the official Java reference (https://github.com/drelhaj/OsmanReadability) on 110 texts: all component counts equal and scores within 1e-6 (`tests/fixtures/osman_reference.json`). The reference documents no interpretation bands, so only the raw score is reported.
* The injected-error mix is synthetic; add a human-written sample before relying on these numbers.
