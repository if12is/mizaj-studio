# Phase 8 (v0.3.0): الأمان، الأداء والحجم، الاستئناف، وحيوية الواجهة

**الهدف:** إصدار 0.3.0 يقوّي التطبيق أمنياً من كل الثغرات المعروفة لتطبيقات Electron + خادم محلي، ويُسرّع فتح التطبيق ويقلّل حجمه، ويضمن استئناف أي تحميل بعد الانقطاع، ويضيف حركة سلسة وحيوية للواجهة دون التضحية بالأداء أو إمكانية الوصول.

> **قواعد ملزمة:** كل إصلاح أمني له اختبار يثبت الثغرة قبل الإصلاح ويمنع رجوعها؛ كل تحسين أداء يُقاس قبل/بعد بأرقام؛ الحركة تحترم `prefers-reduced-motion` ولا تتجاوز ميزانيات الأداء (7.7.2).

---

## Slice 8.1: أمان الخادم المحلي (Backend Security)
- [x] **Task 8.1.1 — رمز وصول لكل تشغيل (Per-launch API token):** Electron يولّد سراً عشوائياً (32 بايت) لكل تشغيل ويمرّره للمحرك عبر `MIZAJ_API_TOKEN`؛ كل الطلبات (عدا `GET /health` العام المختصر) تتطلب ترويسة `X-Mizaj-Token` مطابقة (مقارنة ثابتة الزمن)؛ يمنع أي برنامج محلي أو صفحة ويب من استدعاء الـ API. CORS يقتصر على أصل التطبيق.
- [x] **Task 8.1.2 — حماية DNS rebinding:** رفض أي طلب ترويسة `Host` فيه ليست `127.0.0.1:<port>` أو `localhost:<port>`.
- [x] **Task 8.1.3 — مراجعة مسارات الملفات:** كل endpoint يستقبل مسار ملف: مسارات مطلقة فقط، رفض الأجهزة/الأنابيب/مسارات UNC الشبكية، امتدادات مسموحة، حدود حجم، عدم الكتابة فوق ملفات النظام، وعدم الكتابة خارج المسار المطلوب (symlink).
- [x] **Task 8.1.4 — XML/ZIP الآمن:** `lxml` بدون كيانات خارجية (XXE) أو DTD شبكي، حدود قنابل الضغط (zip bombs) في DOCX/EPUB/الحزم، حدود عمق/حجم XML.
- [x] **Task 8.1.5 — الشبكة والعمليات الفرعية:** فحص allowlist بعد كل إعادة توجيه (SSRF)، رفض العناوين الخاصة/المحلية للموارد البعيدة، استدعاء Tesseract بقائمة وسائط دون shell، مهلات.
- [x] **Task 8.1.6 — الحقن والتسريب:** مراجعة SQL (معاملات فقط)، محرك القوالب (بلا تنفيذ)، عدم كتابة نص المستندات أو الأسرار في السجلات، رسائل الأخطاء بلا مسارات حساسة.
- [x] **Task 8.1.7 — تدقيق الاعتماديات:** `pip-audit` و`npm audit` في CI مع سياسة واضحة، وترقية ما فيه ثغرات معروفة.

## Slice 8.2: أمان Electron (Desktop Security)
- [x] **Task 8.2.1 — تقوية النوافذ:** `contextIsolation`, `sandbox: true`, `nodeIntegration: false`, `webSecurity`, منع `will-navigate`/`window.open`/`webview`، CSP صارم بلا `unsafe-eval`، صلاحيات (camera/mic/geolocation…) مرفوضة افتراضياً.
- [x] **Task 8.2.2 — IPC آمن:** التحقق من مُرسِل كل رسالة (frame URL)، التحقق من أنواع وأحجام الوسائط، عدم تمرير مسارات عشوائية للنظام دون مرورها بحوار المستخدم، `openExternal` لـ https فقط ومن allowlist.
- [x] **Task 8.2.3 — Electron Fuses والتحديث:** _(ملاحظة: الـ fuses الستة مفعّلة؛ ASAR integrity على Windows يحتاج electron-builder ≥ 25 — يُفعَّل فقط إن وُجد الـ digest، وإلا يُترك مع تحذير)_  تفعيل fuses (`RunAsNode` off، `EnableNodeOptionsEnvironmentVariable` off، `EnableNodeCliInspectArguments` off، ASAR integrity)، والتحقق من sha512 للتحديث (electron-updater)، وعدم قبول تخفيض الإصدار.
- [x] **Task 8.2.4 — تخزين الأسرار والبيانات:** عدم كشف الرمز في السجلات، صلاحيات ملفات userData، تنظيف ملفات مؤقتة.

## Slice 8.3: السرعة والحجم (Performance & Size)
- [x] **Task 8.3.1 — قياس زمن الفتح:** قياس آلي (cold/warm) لـ: ظهور النافذة، أول رسم، جاهزية المحرك، أول تشكيل؛ ميزانيات في CI.
- [x] **Task 8.3.2 — فتح أسرع:** شاشة بداية فورية بالشعار، تحميل كسول للمكوّنات الثقيلة (CodeMirror merge، اللوحات القانونية، الإعدادات)، تقسيم الحزمة، تأجيل الأعمال غير الضرورية، تشغيل المحرك بالتوازي مع الواجهة، استيراد كسول في Python (mishkal/onnx/reportlab/pdfminer) لتقليل زمن الـ handshake.
- [x] **Task 8.3.3 — حجم أصغر:** _(قرار: نموذج float يبقى في المثبّت لأن INT8 أسوأ بـ 0.09 نقطة في فئة «عام» بدون علامة الإعراب — حسب قاعدة المالك؛ المحرك 238→190MB دون أي تغيير في المخرجات)_  تقليص المحرك المجمّد (حذف ما لا يُستخدم من numpy/lxml/onnxruntime/البيانات)، استخدام نموذج INT8 فقط في المثبّت، ضغط أفضل للمثبّت، إزالة لغات Electron غير المستخدمة، قياس الحجم قبل/بعد في ملاحظات الإصدار.
- [x] **Task 8.3.4 — خفة الاستخدام:** استهلاك الذاكرة في الخمول، عدم حجب الواجهة، تقليل إعادة الرسم.

## Slice 8.4: الاستئناف بعد الانقطاع (Resilient Downloads)
- [x] **Task 8.4.1 — تحديثات التطبيق:** _(ملاحظة: electron-updater يعيد التنزيل من البداية عند الانقطاع بدل الاستئناف من المنتصف؛ لا يُثبَّت أي ملف ناقص أو تالف بفضل sha512)_  إعادة المحاولة بتأخير متزايد عند انقطاع الشبكة، استئناف تنزيل التحديث (أو إعادة استخدام الأجزاء المنزّلة)، رسالة واضحة، عدم تثبيت ملف ناقص (sha512).
- [x] **Task 8.4.2 — الموارد والنماذج ونص القرآن:** استئناف بـ HTTP Range، التحقق من الحجم والبصمة، إعادة المحاولة التلقائية، التعافي بعد إغلاق التطبيق أثناء التنزيل (حالة محفوظة)، اختبارات انقطاع حقيقية (خادم اختبار يقطع الاتصال).
- [x] **Task 8.4.3 — التشكيل المتدفق والمعالجة الدفعية:** استئناف تلقائي عند انقطاع SSE أو إعادة تشغيل المحرك (من الكاش)، واستئناف مهام المجلد بعد التعطل.

## Slice 8.5: حيوية الواجهة (Motion & Delight)
- [x] **Task 8.5.1 — نظام حركة موحّد:** رموز مدد ومنحنيات (tokens)، انتقالات للنوافذ والقوائم واللوحات والإشعارات، `prefers-reduced-motion`، GPU-friendly (transform/opacity فقط).
- [x] **Task 8.5.2 — شاشة البداية والتحميل:** شاشة بداية بالشعار متحركة بخفة، هياكل تحميل (skeletons)، تقدّم سلس.
- [x] **Task 8.5.3 — تفاعلات دقيقة:** أزرار، مفاتيح، سحب وإفلات، ظهور الحركات بعد التشكيل (fade-in ناعم للحركات الجديدة)، نجاح/خطأ.
- [x] **Task 8.5.4 — قياس:** الحركة لا تكسر ميزانيات الأداء ولا 60 FPS.

## Slice 8.6: الإصدار
- [x] **Task 8.6.1:** CI أخضر، فحص Defender، اختبار التحديث من 0.2.0، اختبار التطبيق المثبّت بالوضع الحقيقي، ثم نشر v0.3.0 مع أرقام الحجم والسرعة في ملاحظات الإصدار.
