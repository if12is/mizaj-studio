# Phase 4: واجهة المحرر التفاعلي للمقالات الضخمة وأدوات التحرير الدقيق (Interactive Editor UI)

**الهدف:** استكمال بناء بيئة التحرير المتقدمة حول محرك **CodeMirror 6** لتعمل بسلاسة تامة مع المقالات الضخمة، مع حل مشكلة إدراج الحركات دون كسر موضع المؤشر، ودعم Undo/Redo واختصارات لوحة المفاتيح.

---

## Slice 4.1: إدارة المستندات الضخمة، السحب والإفلات، وبث التقدم (Large Document UX)
**الهدف:** تجربة سحب وإفلات فورية لملفات `.docx` ومراقبة حية لعملية التشكيل.

### المهام (Tasks):
- [x] **Task 4.1.1:** _(ملاحظة: الامتدادات في `desktop/src/renderer/src/editor/`؛ المحرر للقراءة فقط أثناء التشكيل، وكل تشغيل = خطوة تراجع واحدة)_ بناء امتدادات `CodeMirror 6` المخصصة في `desktop/src/renderer/editor/` لدعم التمرير الافتراضي، تحديد الفقرات، ونظام **`Undo / Redo` المتكامل (`@codemirror/commands` history)** بحيث يمكن للمستخدم التراجع (`Ctrl+Z` / `Cmd+Z`) عن تشكيل فقرة كاملة أو تعديل كلمة واحدة بخطوة واحدة.
- [x] **Task 4.1.2:** بناء منطقة السحب والإفلات (`Drag & Drop DOCX Overlay`) مع معاينة إحصائية فورية قبل بدء التشكيل.
- [x] **Task 4.1.3:** بناء شريط التقدم الحي المرتبط ببث `SSE` يعرض (النسبة المئوية، سرعة التشكيل كلمة/ثانية، زر إيقاف مؤقت `Pause`، وزر استئناف `Resume`).

## Slice 4.2: تعديل الحركات الذري دون كسر المؤشر وتلوين COLR/CPAL (Smart Word Inspector)
**الهدف:** تعديل تشكيل أي كلمة أو حرف واحد بنقرة ماوس دون إفساد موضع المؤشر (Cursor Offset) أو سجل التراجع.

### المهام (Tasks):
- [x] **Task 4.2.1:** تفعيل زر تبديل **تلوين الحركات (`Colored Diacritics Toggle`)** المعتمد على خط `Amiri-Mizaj-Colr.woff2` (`font-palette`) مع إمكانية اختيار لون الحركات (أخضر زمردي أو ذهبي كهرماني) من شريط الأدوات.
- [x] **Task 4.2.2:** بناء **`Word Inspector Popover`** باستخدام **CodeMirror 6 Tooltip & Atomic Transaction API (`view.dispatch({ changes: { from, to, insert } })`)**:
  * بدلاً من الاعتماد على `contenteditable` العادي الذي يكسر موضع المؤشر عند إضافة حركة، يقوم المحرر بحساب حدود الكلمة (`wordFrom`, `wordTo`) بدقة في شجرة حالة CodeMirror (`EditorState`).
  * عند اختيار بديل من اقتراحات `Mishkal` أو النقر على حركة من **لوحة الحركات المصغرة (ـَ ـُ ـِ ـً ـٌ ـٍ ـْ ـّ)** لحرف معين داخل الكلمة، يتم تطبيق التغيير كـ `Transaction` ذري يحافظ على موضع المؤشر (`selection.anchor`) بدقة 100%.
- [x] **Task 4.2.3:** إضافة أزرار **"تعميم على كامل المقال" (`Apply to All Occurrences`)** عبر بحث واستبدال ذري في `EditorState`، وزر **"حفظ في قاموسي الدائم"** الذي يحدث جدول `tashkeel_cache` فوراً.

## Slice 4.3: اختصارات لوحة المفاتيح، المقارنة المزدوجة، والإحصائيات (Shortcuts & Diff View)
**الهدف:** تسريع عمل المدققين اللغويين المحترفين عبر اختصارات سريعة ووضع مقارنة بصري.

### المهام (Tasks):
- [x] **Task 4.3.1:** برمجة **اختصارات لوحة المفاتيح القياسية (Keyboard Shortcuts)**:
  * `Ctrl+Shift+T` (أو `Cmd+Shift+T`): تشكيل النص المحدد أو كامل المقال فوراً.
  * `Ctrl+Shift+R`: إزالة التشكيل من النص المحدد.
  * `Ctrl+Shift+C`: نسخ النص بدون حركات.
  * `Ctrl+Space` (عند وقوف المؤشر على كلمة): فتح نافذة `Word Inspector Popover` وبدائل `Mishkal` بدون استخدام الماوس.
- [x] **Task 4.3.2:** بناء وضع المقارنة جنب إلى جنب (**`Side-by-Side Synced Diff View`**) باستخدام `@codemirror/merge` لعرض النص الأصلي مقابل المشكول مع تزامن التمرير.
- [x] **Task 4.3.3:** لوحة إحصائيات المقال الفورية (عدد الكلمات، نسبة كثافة الحركات، عدد الكلمات المعدلة يدوياً).
