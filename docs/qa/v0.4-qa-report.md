# Mizaj Studio v0.4 - full QA report

Trigger: owner report "many options in Settings don't load/work, e.g. Quran gives an error", a
banner «نص القرآن غير مثبت...» and a spelling tooltip on «1996» suggesting nonsense.

## Method

* Automated + manual exploratory sweeps with Playwright `_electron` under `xvfb-run --no-sandbox`
  (`desktop/tests/qa/explore.mjs`, helpers in `desktop/tests/qa/lib.mjs`). Console errors, failed
  requests (4xx/5xx), raw/English toasts and screenshots are collected per step.
* Real engine (`MIZAJ_MODELS_DIR` = bundled CATT, fast + accurate) and the owner's real document
  (75 paragraphs, 3 tables, 3717 words). Also launched the extracted packaged build (frozen
  sidecar) through CDP: every Settings tab loads there, so the failures are logic bugs, not packaging.
* Surfaces covered: all 8 Settings sections (every control changed, app restarted, values compared),
  Quran (online download with the network blocked, install from a valid / invalid / plain / BOM file),
  online switches and resource catalog, packs (export / import / bad file), backup (export / inspect /
  restore / corrupt), dictionary, glossary, names, every toolbar button (تشكيل، مقارنة، إحصائيات،
  تصدير DOCX، تشكيل الفقرة، بحث واستبدال، قراءة بصوت عال، وضع المراجعة، توحيد النص، وضع الشعر،
  جودة التحرير، تحليل البحر، تدقيق إملائي، قائمة الأخطاء، أدوات قانونية، تحميل النص التجريبي),
  all 8 legal tools, import (txt, md, srt, cp1256, docx, PDF, scanned PDF/PNG, corrupt, empty,
  unknown), export (docx, tracked docx, txt, md, srt, pdf), batch folder, OCR without Tesseract.
* Engine integrity: real-document DOCX conversion in 5 mode/level combinations keeps
  `strip_marks(out) == strip_marks(in)` (base letters never change).

## Verified working (no bug)

All general settings (engine mode, level, font, size, colour, theme, high contrast, update check,
spell switches + categories, confidence, Quran protect, typography) change, apply to the DOM and
survive a restart; online switches persist and default off; the tashkeel run on the real document
(3717 words, ~14 s fast mode) and review mode; paragraph tashkeel; find/replace; diff; stats and
readability; normalize dialog; poetry panel; all legal tools; import/export formats; batch (the corrupt
file is reported per file); OCR without Tesseract shows the Arabic dialog with an install hint;
backup/pack happy and corrupt paths; accurate mode on the bundled model.

## Not fixed / notes

* `tanzil.net` is unreachable from this sandbox (proxy allowlist), so a *successful* online Quran
  download was not exercised end-to-end; the validator and storage are covered by unit tests with a
  synthetic file, and the failure path is verified in the app.
* The legal-terms / names / phrases `.mizajpack` catalog entries point to release assets that do not
  exist yet (HTTP 404). The app now says so clearly; publishing the assets is a release task.
* Catalog entries (resource names/notes/attribution) and the Tesseract install hint come from the
  backend in English (proper nouns and shell commands); left as is.
* The tashkeel button runs on the current selection when there is one (by design); a run on a
  one-character selection finishes instantly. Not changed.
* Toolbar layout of `EditorPane.vue` and `backend/app/engine/*` were intentionally not touched
  (only a 4-line `watch` was added to `EditorPane.vue`).
